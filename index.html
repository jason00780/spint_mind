01 / Fitness · AI

LiftSync — the coach that never skips leg day

A gym workout tracker where all data lives in the user's own Google Sheet. LiftSync pulls today's plan, logs every set, rep and kilo, then an AI backend reads the full training history and writes the next personalised 7-day plan — automatically. No copy-pasting, no manual prompts.

  • Auto-fetches today's workout from Google Sheets on open
  • Set-by-set logging, synced back per workout
  • AI-generated 7-day programming from real history & profile
  • Your data stays yours — it's a spreadsheet you can read
  • React Native · Expo
  • TypeScript
  • Google Sheets API v4
  • Google Drive API
  • AI backend
